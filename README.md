# Hero Cell

## Sobre o Jogo

Hero Cell é um jogo desenvolvido na GameMaker em que o jogador controla uma célula heroica encarregada de combater germes, bactérias e outros microrganismos prejudiciais. O objetivo é sobreviver ao maior tempo possível, eliminando inimigos e fortalecendo o personagem por meio de melhorias adquiridas durante a partida.

Além de proporcionar diversão e desafios, o jogo busca conscientizar os jogadores sobre a importância da higiene e dos cuidados com a saúde, mostrando de forma lúdica como microrganismos podem se proliferar e causar problemas quando não são combatidos.

## Objetivo

Derrote ondas de germes e bactérias, sobreviva ao avanço dos inimigos e evolua seu personagem para enfrentar esse desafio.

## Mecânicas Principais

* Movimentação livre do personagem.
* Combate contra diferentes tipos de microrganismos.
* Sistema de progressão com seleção de melhorias (power-ups).
* Sistema de vida e sobrevivência.
* Tela de pausa e menu principal.

## Controles

| Tecla          | Ação                       |
| -------------- | -------------------------- |
| W              | Mover para cima            |
| A              | Mover para a esquerda      |
| S              | Mover para baixo           |
| D              | Mover para a direita       |
| Mouse esquerdo | Seleciona power-up         |
| P              | Pausar o jogo              |
| Enter / Espaço | Confirmar opções dos menus |


## Mensagem Educativa

A higiene é uma das principais formas de prevenção contra doenças causadas por vírus, bactérias e outros microrganismos. Práticas simples como lavar as mãos, manter ambientes limpos e cuidar da saúde ajudam a reduzir a propagação de agentes infecciosos.

Hero Cell utiliza a temática do combate microscópico para reforçar a importância desses hábitos de maneira divertida e acessível.

## Tecnologias Utilizadas

* GameMaker
* GML (GameMaker Language)
